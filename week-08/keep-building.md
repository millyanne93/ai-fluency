# The Plan to Keep Building

## How to Add the Next Case Study

When I finish a new project, I will add it to my portfolio in under 30 minutes using these steps:

1. **Draft the three beats:** Open my Claude Project ("Portfolio Build — Millyanne") and use the existing structure:
   - **Problem:** What was the gap or need?
   - **What I Did:** What I built and the key decisions I made.
   - **Result:** What came of it (even if it's just "it works" or "I learned X").
   - **Learnings:** What I would do differently next time.

2. **Add the project card:** Copy the HTML structure of an existing project from `#projects` in `index.html` and paste it at the end of the `projectData` array.

3. **Add supporting evidence:** Take a clean screenshot (if applicable) and link to the GitHub repo and any live demo.

4. **Review:** Read it out loud to check the tone matches my voice card.

5. **Deploy:** Drag the updated folder to Netlify Drop.
